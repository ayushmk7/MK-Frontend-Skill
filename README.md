# MK frontend design language

[MK-Frontend-Skill.md](MK-Frontend-Skill.md) is the design reference for MK interfaces. It defines one palette and type system across page types, the BB8 light/dark switch, layout, components, accessibility, and motion.

Use `#2563EB` as the only UI blue. On landing pages and websites, let the header and hero fill the first viewport, and keep short headings on one line when they fit. Omit eyebrows and dropdowns. Keep cards white in light mode and black in dark mode, without grain, gradients, blur, or shadows; separate the sidebar with the same quiet edge used on cards. Nested surfaces use a 32px outer radius, 8px gap, and 24px inner radius.

This repository is a design guide, not an installed `SKILL.md`.
