# MK frontend design language

[distinctive-frontend.md](distinctive-frontend.md) is the design reference for MK interfaces. It defines one palette and type system across page types, the BB8 light/dark switch, layout, components, accessibility, and motion.

Use `#2563EB` as the only UI blue. On landing pages and websites, let the header and hero fill the first viewport. Omit eyebrows and dropdowns; keep cards white in light mode and black in dark mode, without grain, gradients, blur, or shadows.

This repository is a design guide, not an installed `SKILL.md`.
