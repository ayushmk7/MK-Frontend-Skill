# MK frontend design language

[distinctive-frontend.md](distinctive-frontend.md) is the design reference for MK interfaces. It defines the shared palette, BB8 light/dark switch, layout, components, accessibility, motion, and three MK expressions.

Use `#2563EB` as the only UI blue. Lead with the hero, omit eyebrows, and keep dark-mode boxes opaque black without grain, gradients, blur, or shadows.

This repository is a design guide, not an installed `SKILL.md`.
